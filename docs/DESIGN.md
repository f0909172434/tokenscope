# Design proposition

把語言模型拆成一張可以調旋鈕的實驗桌。每一條線、每一塊色彩都對應實際數值；使用者改變一個條件，就能看见資訊如何流動、機率如何重分配，以及字元如何組成 token。

The visitor begins inside an attention experiment, follows a short guided experiment, then changes to sampling or BPE. Every module pairs one central interactive instrument with concise controls, a numerical readout, and a concept check.

The visual language borrows from scientific instruments: dark forest work surface, acid-green active signals, neutral paper surroundings, large figures, numbered experiment tabs, and restrained grid rules. Motion belongs to signal paths, probability widths, and merge transitions. Reduced-motion mode keeps all numerical feedback.

Intentional omissions: no generated imagery (the data is the image), no model API (these mechanics are deterministic and inspectable), and no course-completion badges (three exercises cannot establish mastery).

All interface copy is authored in Traditional Chinese and English. Synthetic vectors and a word-based character BPE are labelled explicitly. The lab is independent educational software and is not affiliated with Stanford or a model provider.
