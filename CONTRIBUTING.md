# Contributing

Small, focused fixes and clear educational explanations are welcome.

1. Open an issue with a reproducible example and the expected arithmetic or behavior.
2. For a code change, create a branch and preserve both interface languages.
3. Add a numerical regression for a mathematical fix; exercise the actual control for an interaction fix.
4. Run `npm test`, `npm run build`, `npm run test:e2e`, and `npm run format:check`.

Keep the examples synthetic and the app usable without an API key. Do not add analytics, account requirements, private course material, or unlicensed assets. Distinguish a teaching simplification from a production tokenizer or model implementation.

See `docs/MATH.md` for the filtering and merge conventions. Please discuss changes to these conventions explicitly, because they affect exported experiments.
